# SkillConnect

SkillConnect is a full-stack web application built with Flask that connects students based on the skills they can teach and the skills they want to learn. The platform promotes collaborative peer-to-peer learning by enabling users to discover suitable learning partners, request sessions, manage bookings, and share feedback after each session.

Designed with an intuitive user interface and a modular backend architecture, SkillConnect streamlines the process of knowledge sharing within a student community while encouraging skill development through meaningful interactions.

## ✨ Features

- 🔐 Secure user registration and authentication
- 👤 Personalized user profiles
- 🎯 Smart skill-based matching system
- 📚 Request and book learning sessions
- 📅 Manage upcoming and completed sessions
- ⭐ Rate and review learning experiences
- 📊 Interactive user dashboard
- 🌙 Responsive interface with dark mode support
